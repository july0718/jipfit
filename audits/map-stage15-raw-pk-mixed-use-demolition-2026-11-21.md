# 집핏 15차 — 169개 원문 PK·동 검증과 현행 주거동 후보 미발견 424개 재검증 (2026-11-21)

기존 14차에서 선별한 169개 A급과 원지번 현행 아파트 주거동 필터에 걸리지 않은 424개, 총 **593개 단지**에 대해 건축HUB **9,188개 지번 원본 JSON**을 직접 재대조했다. 작업은 **읽기 전용**이며 PostgreSQL·원본 실거래·예측·좌표·단지 ID·지도 제외 목록 변경 **0건**, API 재호출 **0회**다.

## 169개: 건축물대장 현행 표제부·관리번호(PK) 직접 교차검증

| 분류 | 수 | 한계 |
|---|---:|---|
| **단일 동 거래명 + 현행 동일 지번 표제부 + 명칭·동번호·사용승인연도 + 1개 고유 PK 직접 일치** | **97** | 현존 근거 강함. 다만 서비스 `active` 일괄 적용 **전 승인 필요** |
| 현행 표제부의 이름·연도·PK 확인, 원 거래 ID의 전체 동 범위 미확정 | **72** | 추가 동별 범위 대조 필요 |
| 합계 | **169** | 신규 멸실 확정 0 |

강한 97개를 판별할 때 현행 주건축물 표제부, 주거용도, 단일 PK, 거래명에 명시된 **정확한 한 개의 동번호**, 원본 승인연도 일치 및 동일명 폐쇄·승인 후 철거 완료 충돌 부재를 요구했다. 청담동 `삼환(101동)` ↔ 현행 `삼환아파트 101동`(PK `102411946`, 1999-11-30 사용승인) 등의 원문 증거가 있다.

## 424개: 기존 ‘현행 아파트 주거동 후보 없음’의 분류 누락 발견

종전 필터가 현행 표제부의 **주용도 `업무시설`·`근린생활시설`** 이면서 **기타용도에 공동주택·도시형생활주택·아파트**가 기재된 복합용도 건물을 놓치고 있었다.

| 원본 재검사 등급 | 수 |
|---|---:|
| 현행 주거용도 + 원 거래명·사용승인연도 일치 | **103** |
| 현행 주거용도 확인, 원 거래 동 범위 미확인 | **59** |
| 현행 표제부 확인, 주거용도 입증 부족 | **39** |
| 현행 비표제부 기록만 존재 | **3** |
| 현행 표제부 없음 + 폐쇄말소 기록 | **143** |
| 현행 표제부 없음 + 폐쇄말소·철거 기록 | **54** |
| 3종 API 모두 기록 0 | **23** |
| **합계** | **424** |

- 현행 건축물대장 **원본 기록이 존재하는 단지 209개**, 기록 0인 단지 **215개**.
- 주용도 또는 기타용도에 주거용도가 있는 현행 표제부 **162개 단지**. 그중 **103개는 단지명·사용승인연도도 정합**. 그러나 복합용도 내 원 거래 주택/동/호 범위까지 입증된 것은 아니므로 **현존 확정 불가**.
- 예: 전농동 `다스하우스`, 신설동 `포레스트힐시티`, 용두동 `동대문베네스트`.
- 폐쇄 표제부의 원단지명·사용승인연도와 철거 완료 건의 **연면적·세대수 1:1 정확 일치** 조건으로 신규 멸실 확정 가능한 경우 **0건**. **말소≠물리적 철거 확정**.
