# 집핏 10차 — 서울 전체 단지 존치 전수검증으로 범위 확대 (2026-11-21)

## 검증 범위 변경

지금까지는 지도 좌표 누락 및 표시 보류 단지를 우선 조사했다. **좌표가 있는 단지는 존치가 입증된 것이 아니므로**, 운영 PostgreSQL의 모든 `complexes.complex_id`를 기준으로 전수검증을 확대한다.

- 사용자 제공 9,188개 건축HUB 지번 JSON 원본 전체를 로컬에서 읽기 전용 재검사했다.
- 원본 구형 파일 2,728개에는 종전 `complex_ids` 문자열이 있으나, 후속 수집 파일 6,460개에는 개별 `complex_id`가 없다.
- **9,188개는 고유 지번 수**이며 실제 단지 ID 수는 운영 `complexes`에서 별도 산출해야 한다.
- 현행/폐쇄말소/철거멸실 3종 수집이 완료됐다고 해서 기존 거래 단지와 현행 건물의 동일성까지 확인된 것은 아니다.

## 지번별 1차 위험 선별 결과

주거동 표제부는 8차에서 사용한 동일 필터: 주용도 '공동주택', 주건축물, 상가동·경비실 등 제외, `etcPurps`에 아파트 포함 또는 세대수 양수.

| 구분 | 지번 수 | 현행 공동주택 주거동 후보 있음 | 후보 없음 |
|---|---:|---:|---:|
| 원본 구형 | 2,728 | 2,433 | 295 |
| 후속 수집분 | 6,460 | 6,292 | **168** |
| **전체** | **9,188** | **8,725** | **463** |

- 후속 수집분에서 현행 아파트 후보가 없는 지번 168개 중, **14개는 폐쇄말소대장에 주거동 후보가 존재**, 154개에는 그런 후보가 없다.
- 후속 수집분 중 **346개 지번**에는 현행 주거동과 *주거용 전체 철거/멸실* 기록이 병존하고, **463개**에는 현행 주거동과 과거 주거동 폐쇄말소 기록이 병존한다.
- 같은 지번의 철거·폐쇄 기록은 **다른 건물/동에 관한 것일 수 있다**. 이 건수를 현재 단지 멸실 확정 수로 사용할 수 없다.
- 위 숫자는 **지번별 예비 선별 결과**이며, 각각의 단지 ID에 대한 최종 현존/멸실 판정이 아니다.

## 전체 단지 전수검증 실행 순서

1. 운영 DB에서 `complex_id,name,address,built,latitude,longitude,existence_status` 전체를 CSV로 **읽기 전용** 추출하여 진짜 단지 분모와 좌표 상태 확정.
2. 전체 단지 ID를 9,188개 원본 지번과 연결. 구형 원본의 `complex_ids` 직접 연결 + 지번주소 기준 연결 + 다중 단지/동/지번 혼합을 각각 별도 표기. ID 누락은 자동 폐기하지 않음.
3. 기존 좌표 보유 단지를 포함하여 현행 건축물 관리번호, 건물명·동명, 준공연도, 도로명주소 등과 역매칭. 현재 건물이 다른 연식으로 교체된 재건축 사례는 원건물과 **다른 개체로 판단**.
4. 원지번 현행 주거동 없음/과거 철거 기록 병존/이전 지번/현행 동명 불일치/기존 복구·중복 상태를 각각 검토 큐로 분리.
5. 판정은 `현존 확인 / 원건물 멸실 확정 / 미확정`과 별도 `원건물↔현재 건물 연결증거`로 저장; **과거 거래·단지ID·예측 기록 삭제/변경 금지**.
6. 충분한 직접 증거가 확보되기 전까지 운영 지도 제외 상태를 자동 변경하지 않는다.

## DB 단지 원본 내보내기 (PowerShell, 프로젝트 루트)

```powershell
docker compose exec -T db psql -X -q -v ON_ERROR_STOP=1 -U jipfit -d jipfit -c "COPY (SELECT complex_id, name, address, built, latitude, longitude, existence_status FROM complexes ORDER BY complex_id) TO STDOUT WITH (FORMAT CSV, HEADER TRUE)" > "$HOME\Downloads\jipfit_all_complexes.csv"
(Import-Csv "$HOME\Downloads\jipfit_all_complexes.csv").Count
```

**주의:** 본 명령은 읽기 전용이며 DB를 변경하지 않는다. 정확한 단지 수/좌표 보유 수는 해당 파일에서 확인해야 한다. 본 작업에서 PostgreSQL, 지도 제외 목록, 좌표, 실거래·예측 데이터는 변경하지 않았다.
